# Kredit Foto

Seluruh foto produk dan foto suasana di situs ini diambil dari **Unsplash**
dengan lisensi [Unsplash License](https://unsplash.com/license), yaitu gratis dipakai
untuk keperluan komersial dan non-komersial tanpa kewajiban mencantumkan nama.

Atribusi tetap disertakan di sini sebagai Referensi. Jika sebuah foto perlu diganti,
cukup ganti berkas di `assets/img/produk/` lalu perbarui nama file pada `assets/js/data.js`.
